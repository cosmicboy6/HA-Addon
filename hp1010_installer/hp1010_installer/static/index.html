HP1010 Print Server Installer

Build and flash the ESP32-S3 firmware for the HP LaserJet 1010 print server.

1 Settings

These values are written into the device firmware. Your WiFi password stays on this Home Assistant instance (/data) and is never uploaded anywhere.

2 Build firmware

Compiles the firmware with your settings. The first build downloads the ESP32 toolchain and can take several minutes; later builds are much faster (cached in /data).

3 Flash over USB

Plug the ESP32-S3 into the Home Assistant host with a data USB cable. Select the port, then flash the firmware you just built.

The bundled prebuilt image needs no build: it boots a HP1010 Print Fallback access point so you can set the WiFi later. Use the normal flash once you have built your own firmware.
